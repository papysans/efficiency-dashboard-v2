# 页面说明书 · 平台客观指标（平台总览 / 实时报表 / 实时查询）

> 路由 `/kanban/platform/overview`、`/platform/realtime`、`/platform/realtime/query`
> 组件 `frontend-react/src/pages/platform/*`
> 数据接口 chat 代理 `/api/v2/chat/*`（后端 `chat_proxy_handler.go:41`）

---

## 0. 这三页是什么（共同前提）

这三页是**平台客观指标**——LLM 调用的请求量/Token/成本/错误率/缓存命中/模型分布等。

> ⚠️ **置信源边界**：这些指标的数据与计算口径**全部来自外部服务 `chat-indicator-statistics`**。本系统后端只做**反向代理**（`/api/v2/chat/<path>` → `<chat 服务>/chat-indicator-statistics/api/v1/<path>`），**不在本系统做任何指标计算**。因此本册不展开各指标公式——其口径以 chat 服务为准。本系统唯一的"口径性"加工是平台总览 KPI 的**区间求和/日均/错误率比值**（因日去重不能直接相加，`PlatformOverview.tsx:215-236`），其余都是展示层格式化（数字缩写、时间格式、错误码判定、用户名互链）。

**总开关**：后端配置 `chat_stats.base_url` 为空时，这三页不可用、显示"平台指标服务未启用"，左侧"平台"导航整组隐藏。

---

## 1. 平台总览（PlatformOverview）

**用途**：基于 chat 侧**历史日汇总**的平台指标。
**主要内容**：KPI（总请求/活跃用户日均/输入·输出·缓存 Token/错误率/总成本¥）+ 趋势图（成本/Token/请求量/缓存命中率）+ 排行表（模型成本 Top10 / 用户 Top50）。
**数据**：5 个 chat 端点（`/stats/global/daily`、`/stats/cost-trend`、`/stats/cache-hit-rate`、`/stats/models/cost-ranking`、`/stats/users/ranking`）。
**时间**：近 7/30/90 天 + 自定义；按日粒度；无手动刷新（React Query 缓存）。
**用户名互链**：chat 的 `universal_id` 与看板 `user_id` 同源，表里用户名解析为看板真名并可点进用户详情（仅展示增强，不改指标值）。

## 2. 实时报表（RealtimeReport）

**用途**：直查源库的**实时聚合**（近 30 分/1 小时/3 小时，每分钟粒度）。
**主要内容**：KPI（请求量/活跃用户/Token/错误请求/实时费用）+ 趋势图（Token/缓存命中率/请求量）+ 模型请求分布环图 + **Auto 路由细分**（auto 请求实际路由到哪些模型）+ 模型详情表 + 请求量 Top50 用户。
**数据**：单端点 `/stats/realtime`。
**刷新**：手动刷新按钮，**服务端 10 秒全局限频**（换档/刷新后 10s 倒计时禁用）。

## 3. 实时查询（RealtimeQuery）

**用途**：按条件**点查单条 LLM 请求明细**（直查源库，最多 100 条），现场排查用。
**主要内容**：结果表（时间/Request ID/Universal ID/用户名/Model/Routed/状态/Token/耗时）+ 行详情弹层（含 TTFT、slow_chunk、system/user tokens 等原始字段）。
**数据**：单端点 `POST /stats/detail/query`。
**过滤**：时间范围（必填）+ Universal ID / Request ID / Model / Routed Model / 是否错误 / 条数 / 排序方向（全部精确匹配，提交前 trim）。无分页、无自动刷新。

## 4. 边界与常见质疑应答

**Q：平台页打不开 / 显示"未启用"？**
后端未配置 `chat_stats.base_url`（平台指标服务未接入）。这是部署配置项，非故障。

**Q：实时报表刷新点不动？**
有 10 秒全局限频，刚查过需等冷却（按钮会倒计时）。多人同刷可能撞限频，错误条会提示"请 N 秒后再试"。

**Q：这些成本/Token/错误率是看板算的吗？**
不是。全部由外部 chat-indicator-statistics 服务计算，本系统只代理转发与展示。具体口径（如成本估算、缓存命中率定义、TTFT 测量）以该服务为准，本系统不可见、不可改。

**Q：成本币种是人民币吗？**
界面显示 `¥`，但实际币种由 chat 服务的 `system_currency` 系统配置决定，若上游配置为其它币种，符号可能与实际不符。
